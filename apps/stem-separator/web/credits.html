Built on open research.

The interface and local processing workflow are part of Tech with DV. The model estimates six categories; it does not recover the original studio recordings.

Separation model

HT-Demucs 6-stem ONNX conversion by StemSplit, based on the Demucs research by Rouard, Massa, and Défossez. The app downloads the public model directly from Hugging Face at a pinned version, then checks its SHA-256. The conversion’s publisher labels it MIT. We do not host a copy of its weights in this website repository.

Model revision: 49df9b6989cf2150840ea65b0bef77a2e471b678
SHA-256: 7ce55792e2231c93fbf92de95f5fd5b3a5e6c89f7db690dfd693e8f1dce56869

Runtime

ONNX Runtime Web 1.31.1 by Microsoft, MIT license. Runtime files load from the jsDelivr public CDN. Inference runs on the browser CPU in a local background worker.

Browser integration

Model shape, stem order, and overlap-add integration follow the demucs-onnx reference project. The overlap window in this app retains nonzero endpoints to preserve boundary samples.

Privacy and storage

Audio is read and processed on your computer. This app has no audio-upload endpoint, separation API, account, or analytics. GitHub Pages, the runtime CDN, and the model host receive normal requests for their public files. The browser can cache the model if you choose; the app stores no song files between visits. Close the tab to release its in-memory audio, or use Clear downloaded model to remove its model cache.
